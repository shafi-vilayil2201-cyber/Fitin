# Fitin Backend

Fitin is a fitness platform backend built using ASP.NET Core and Clean Architecture.

## Architecture

- API Layer
- Application Layer
- Domain Layer
- Infrastructure Layer

## Features

- Authentication (JWT)
- Product Management
- Cart Management
- Wishlist Management
- Cloudinary Image Upload

## Tech Stack

- ASP.NET Core 8
- Entity Framework Core
- SQL Server
- JWT Authentication
- Cloudinary

## Run Project

```bash
dotnet restore
dotnet run
